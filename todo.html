How it works

  • Add a task by typing it in the box and pressing Add (or Enter).
  • Each task shows up in the list, in the order you added it.
  • Tick a task's checkbox to mark it as completed. Untick it to undo.
  • The Delete button removes a task from the list.
  • Every change is saved with localStorage, so the tasks are still here after you refresh or reopen the page. They stay in this browser only.
